## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 📅 智能课表 | 一句话录入课表，自动生成周视图，支持导出 |
| 🎓 选课助手 | 按学分、时间冲突、抢课成功率推荐课程组合 |
| 🍜 校园生活 | 食堂窗口排队与营业时间查询、图书馆座位预约提醒 |
| 📚 学业问答 | 基于校园手册与院系文件的检索问答（RAG） |
| 🤖 智能对话 | 多轮上下文，支持多角色人格切换 |
